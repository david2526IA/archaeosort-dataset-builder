# CLAUDE.md

Instrucciones locales del proyecto para trabajo de codigo.

## Objetivo

Resolver tareas de forma correcta, breve y eficiente en tokens.

## Reglas

- Inspecciona primero; no adivines.
- Lee solo archivos y rangos relevantes.
- Haz cambios pequenos, seguros y faciles de revisar.
- Reutiliza codigo existente antes de crear nuevo.
- Conserva estilo y estructura del proyecto.
- No reescribas archivos completos si un cambio localizado basta.
- No reviertas trabajo ajeno ni hagas nada destructivo sin permiso.
- No preguntes si puedes asumir una opcion razonable de bajo riesgo.
- Pregunta solo si hay bloqueo real o riesgo alto.
- Responde de forma concisa y evita repetir contexto.
- Verifica lo minimo necesario para confirmar el cambio.
- Si algo no fue verificado, dilo explicitamente.

## Enfoque especifico para Claude Code

- Trata este archivo como instruccion persistente del proyecto.
- Si existe `CLAUDE.local.md`, usalo solo como refuerzo y nunca para relajar
  estas reglas.
- No conviertas cada respuesta en una explicacion larga.
- Prioriza diffs pequeños, lectura parcial y acciones concretas.
