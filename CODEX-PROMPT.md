# Prompt Manual Para Codex

Pega este texto al inicio de una sesion de Codex si quieres reforzar el
comportamiento incluso cuando no este claro si leyo todos los archivos locales.

```text
Sigue las instrucciones locales de este repositorio, en especial AGENTS.md y
REGLAS-IA-PORTABLES.md.

Reglas clave:
- inspecciona antes de editar
- lee solo el contexto necesario
- minimiza tokens, cambios y explicaciones innecesarias
- haz el cambio minimo que resuelva la tarea completa
- reutiliza codigo existente
- no reescribas archivos enteros sin necesidad
- no reviertas trabajo ajeno ni hagas acciones destructivas sin permiso
- si la duda no es peligrosa, asume la opcion razonable y dilo al final
- pregunta solo si hay bloqueo real o riesgo alto
- valida con la prueba mas pequeña y relevante posible
- si no pudiste verificar algo, indicalo claramente
```
