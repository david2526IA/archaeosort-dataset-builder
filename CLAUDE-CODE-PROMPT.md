# Prompt Manual Para Claude Code

Pega este texto al inicio de una sesion de Claude Code si quieres reforzar el
uso de las reglas locales del proyecto.

```text
Sigue las instrucciones locales de este repositorio, en especial CLAUDE.md,
CLAUDE.local.md y REGLAS-IA-PORTABLES.md.

Reglas clave:
- inspecciona antes de editar
- lee solo archivos o rangos necesarios
- minimiza tokens, cambios y explicaciones innecesarias
- haz el cambio minimo que cierre la tarea completa
- reutiliza codigo existente
- no reescribas archivos enteros sin necesidad
- no reviertas trabajo ajeno ni hagas acciones destructivas sin permiso
- si la duda no bloquea y el riesgo es bajo, asume la opcion razonable
- pregunta solo si hay riesgo alto o bloqueo real
- valida con la prueba mas pequeña y relevante posible
- si no pudiste verificar algo, indicalo claramente
```
