# Portable Windsurf Rules

Repository-local operating rules:

- Work efficiently and save tokens.
- Understand the codebase before editing.
- Read only the necessary context.
- Make minimal, safe, maintainable changes.
- Reuse what already exists.
- Preserve style and structure.
- Avoid rewriting whole files if a focused diff is enough.
- Do not undo user work without permission.
- Assume reasonably when risk is low; ask only if blocked or risky.
- Keep answers concise.
- Verify the change when practical and say what was not verified.

Also follow `REGLAS-IA-PORTABLES.md` if present.
