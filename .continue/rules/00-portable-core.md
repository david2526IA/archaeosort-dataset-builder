# Portable Continue Rules

Apply these local repository rules:

- Minimize token usage without sacrificing correctness.
- Inspect before changing code.
- Read only relevant files and sections.
- Prefer the smallest complete fix.
- Reuse existing code and avoid unnecessary dependencies.
- Preserve project conventions.
- Avoid full-file rewrites when a local edit is enough.
- Do not revert unrelated user changes.
- Ask only if blocked or if the risk is high.
- Keep responses concise and action-oriented.
- Verify with the smallest relevant test or check.
- State clearly what was not verified.

See `REGLAS-IA-PORTABLES.md` for the full policy.
